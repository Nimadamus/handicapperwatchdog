## Cache invalidation
`build.py` refetches a profile whenever the tracker's record for that account changes (record, graded count, units,
last pick), not only on a new post. Changed records are fetched first with their own budget (`HWD_MAX_FETCH_CHANGED`,
default 1000 per run); untouched profiles refresh once a day. A detailed profile is published only when it matches the
ranking row of the same build; otherwise the page shows the current headline record and says the breakdown is rebuilding.
